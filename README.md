# KIS Desk

한국투자증권 국내 주식 API를 사용하는 Windows 트레이딩 대시보드의 배포 저장소입니다.

## 다운로드와 실행

1. [최신 릴리스](https://github.com/bhb414/kisdesk-releases/releases/latest)에서 `KISDesk-버전-windows-x64.zip`을 받습니다. GitHub가 자동으로 만드는 `Source code` 압축 파일은 실행 프로그램이 아닙니다.
2. ZIP을 새 폴더에 모두 압축 해제하고 `KISDesk.exe`를 실행합니다. `_internal` 폴더도 함께 유지합니다.
3. 브라우저의 연결 설정에서 본인의 한국투자증권 API 키와 계좌를 입력합니다. 별도 Python이나 GPU 설치는 필요하지 않습니다.
4. 검은 로그 창을 유지합니다. 정상 종료는 그 창에서 `Ctrl+C`를 누르고 실행 정리 완료를 기다립니다.

홈의 차트·호가·순위·관심종목·잔고, 통계, 중앙 운영 상태, 블록·Python 에이전트를 제공합니다. 자동매매는 사용자가 예산과 조건을 설정하고 실행해야 하며, 재시작 후 실전 매매도 직접 재개해야 합니다.

## 업데이트

0.2.5부터 앱이 시작할 때 이 저장소의 새 버전을 확인합니다. **연결 설정 → 앱 정보**에서 직접 확인할 수도 있습니다. 업데이트 버튼을 누르면 다운로드와 제작자 서명 검증을 거쳐 다음 실행을 준비합니다. 실행 중인 매매 서버를 강제로 재시작하지 않습니다.

## 개인 데이터와 서명

- 개인 설정·API 키·에이전트·매매 기록은 `%LOCALAPPDATA%\KISDesk`에 보관하며 이 저장소와 배포 ZIP에 포함하지 않습니다.
- 업데이트는 앱에 등록된 제작자의 Ed25519 서명과 파일 해시를 검증합니다. 서명용 개인키는 배포 파일에 포함하지 않습니다.
- 서명 검증은 배포 출처와 파일 변조를 확인합니다. 전략의 수익이나 소프트웨어의 무결점을 보증하는 기능은 아닙니다.
- 제작자 공개키 지문: `512ef0b88dc2f9c5ea5ebd30b71c4bee8a2e5be7389d077ccd04fc8da2652efa`

문제를 신고할 때 API 키·계좌 설정 파일·인증 토큰·개인 매매 기록을 공개하지 마세요.
